Server internet egress · Tanium 15-day report, approx. Sept 1–16, 2026

Egress by Data Center

Server internet connections leaving through the egress firewalls at Middletown, Windsor, RI and Shea, split into traffic that went through a proxy first and traffic that went direct to the firewall, by protocol (HTTP vs HTTPS), and by where the servers sit.

Proxied vs direct, by data center

Connections leaving each data center's egress firewalls. Proxied means the server connected to a proxy (Aetna PAC or Skyhigh) and the proxy's own traffic left through that site; direct means the server's connection went straight to the egress firewall.

HTTP vs HTTPS, by data center

Protocol is visible only for connections the server makes directly to an internet address (by destination port). Connections to an explicit proxy (Aetna PAC on 9119, Skyhigh F5 VIPs on 8080/9119) show only the proxy port, so whether the request behind them is HTTP or HTTPS is not visible in Tanium.

Where the traffic comes from

Share of each data center's egress connections by the location of the server that started them. Traffic from other sites and from the cloud is backhauled to that data center, either to its proxies or because the server's routing domain egresses there.

Scope. Tanium server connections only (application servers, Citrix servers and servers with no APM ID); user traffic is mostly on Zscaler and is not in this page. ZPA App Connectors are excluded. Counts are connections over the 15-day window, not bytes.

Shea proxy share includes WCCP. Direct Shea traffic matched by the WCCP redirect lists on PAZSHDC-SEC-INTWIR-01 (replayed against the 2026-09-09 configs) is counted as proxied. RI has no WCCP redirection in effect (line 1 of wccp_95 is deny ip any4 any), so RI proxied traffic is explicit F5 VIP traffic only.

Aetna proxies egress through Cisco FTDs (mid/win-fw-proxy-ftd), not Palo Alto. Aetna direct server and user traffic leaves through the GLR Palo Altos. RI proxy-farm egress through RRIWSCP-SEC-EXT-EMPTEMP is inferred (no NAT record).

HTTP vs HTTPS. Port 443 is counted as HTTPS and port 80 as HTTP; the few connections that used both (about 61K) are counted as HTTPS. At Shea, the HTTPS and HTTP figures are the servers' own connections before WCCP: about 2.1M of Shea's direct connections are redirected to Skyhigh by WCCP, so they reach the internet through the proxy. Port 9997 is the Splunk forwarder port; all of it goes to Amazon Web Services addresses, consistent with a cloud-hosted Splunk indexer. Other ports include Google push (5228), Kafka (9092), SIP-TLS (5061) and AMQP-TLS (5671).

Origin is the server's IPAM location. Proxied flows are attributed to the proxy's site; direct flows to the egress of the server's IPAM routing domain. "Other" is servers at other sites or unresolved.

Not in this page: Las Vegas (2.88M direct), the Azure, GCP and AWS egress firewalls, provider-local cloud endpoints, and Zscaler.
